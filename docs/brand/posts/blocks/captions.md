## LinkedIn (no link in the post — first comment)

Image: blocks-hero.png (or all four as a carousel: hero, 1, 2, 3)

Screenspell just learned new building blocks.

Until this week, when you asked for a hotel app, it drew the calendar by hand every time. Sometimes well, sometimes not.

So I built the parts top apps share, and reviewed every one before shipping:
→ a month calendar for picking a stay
→ a week strip for habits and workouts
→ order tracking, step by step
→ star ratings with the breakdown
→ story rings and "who's going"
→ a one-time code input
→ bottom sheets, action sheets, toasts and a side drawer

Now when you describe an app, the right block shows up where it belongs. Dates get a calendar. A delivery gets a timeline. Reviews get stars.

The best part: screens with a visible problem went from 19% to 3% on my test set.

Link's in the comments. Try it with your own idea 👇
